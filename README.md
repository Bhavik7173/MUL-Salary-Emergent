# MUL Salary Tracker

A full-stack payroll and work-hours platform for recording daily work, calculating earnings and allowances, importing spreadsheets, and generating payslips.

## Highlights

- Daily work entries
- Automated payroll calculations
- CSV and Excel import
- PDF payslip generation

## Technology stack

React, FastAPI, MongoDB, ReportLab, Pandas
